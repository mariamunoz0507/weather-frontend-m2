# App de Clima - Módulo 2 ☁️

Este es el Producto Mínimo Viable (MVP) de una aplicación de clima regional. El proyecto permite visualizar el estado del tiempo de 10 localidades diferentes y acceder a información detallada mediante una interfaz interactiva y responsiva.

## 🚀 Funcionalidades
- **Home**: Grilla responsiva con 10 localidades principales.
- **Detalle**: Vista ampliada que incluye Humedad, Viento y pronóstico semanal mediante Modales de Bootstrap.
- **Interactividad**: Uso de jQuery para la manipulación dinámica del DOM.
- **Diseño**: Basado en Bootstrap 5.3 con enfoque Mobile-First.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica.
- **CSS3**: Estilos personalizados y Google Fonts (Roboto).
- **Bootstrap 5.3**: Framework de diseño y componentes.
- **jQuery 3.6.0**: Lógica de interacción y eventos.
- **Git**: Control de versiones con historial de commits descriptivos.

## 📦 Instalación y Ejecución
1. Clonar el repositorio o descargar los archivos.
2. Abrir el archivo `index.html` en cualquier navegador moderno.
3. (Opcional) Si usas VS Code, se recomienda usar la extensión **Live Server**.
